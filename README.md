# Ashuuya — Citrus-based-vibecoded ShikimoriRIP theme

Тема оформления для Shikimori RIP. Citrus, Monocolor и Cosmo — её исходные компоненты.

## Что означают компоненты

- **Citrus** — базовый дизайн профиля и боковых списков (`prof_form_citrus`).
- **Monocolor** — оформление списков и связанные монохромные элементы (`q02_monocolor_citrus_list`).
- **Cosmo** — дополнительные компоненты Cosmo, включая панель быстрого доступа и слайдеры профиля.
- **RIP adaptation** — адаптации для Shikimori RIP.

## Установка

1. Откройте Shikimori RIP и найдите поле пользовательского CSS в настройках профиля.
2. Скопируйте туда строку ниже целиком, одной строкой:

```css
@import url("https://raw.githubusercontent.com/ashuuya/ashuuya-shikimori-theme/v1.2.3/ashuuya-shikimori-theme.css");
```

3. Сохраните настройки и обновите страницу.
4. Если оформление не изменилось, обновите страницу с очисткой кэша: `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (macOS).
5. Проверьте профиль на широком и на мобильном экране.

Импортируемый CSS загружается Shikimori и встраивается в пользовательский стиль. `@import` сокращает текст в поле настроек, но сам CSS остаётся того же размера и кэшируется сайтом.

## Файлы

- `ashuuya-shikimori-theme.css` — единственный файл, который нужно подключать. Содержит полную тему вместе с адаптацией под RIP; отдельный модуль не требуется.

Не подключайте к теме посторонние фрагменты и не вставляйте её содержимое повторно вторым `@import`.

## Своё оформление

Тема собрана так, что её можно перекрасить и заменить картинки, не редактируя файл. Добавьте в поле пользовательского CSS **после** строки `@import` только нужные строки:

```css
html:root {
  --ash-font: "Inter", sans-serif;
  --ash-logo: url("https://example.com/my-logo.png");
  --ash-bg-image: url("https://example.com/my-background.jpg");
  --ash-ach-bg: url("https://example.com/achievements.jpg");
  --ash-density: 0.8;
  --ash-nav-position: sticky;
}
```

| Переменная | За что отвечает | По умолчанию |
|---|---|---|
| `--ash-font` | шрифт всей темы | `"Comfortaa", sans-serif` |
| `--ash-logo` | картинка логотипа в верхнем меню | логотип Shikimori RIP |
| `--ash-bg-image` | фон страницы | фон темы |
| `--ash-ach-bg` | фон раздела достижений | фон темы |
| `--ash-density` | плотность: меньше 1 — компактнее отступы между карточками и строками списков | `1` |
| `--ash-nav-position` | `relative` — меню уезжает при прокрутке, `sticky` — остаётся сверху | `relative` |

Если не указывать переменные вообще, тема выглядит так, как задумана: значения по умолчанию уже подставлены.

Плотность меняет только вертикальные отступы. Сколько карточек в ряду и сколько избранного показывать в профиле — это настройки самого сайта, тема их не переопределяет. Закрепление меню по умолчанию выключено: включите его через `--ash-nav-position: sticky`.

`--ash-density` — экспериментальная настройка: на части страниц отступы могут не измениться или выглядеть иначе. Значение по умолчанию `1` ничего не меняет.

## Обновления

Строка выше закреплена на теге `v1.2.3`, поэтому стиль не изменится неожиданно: изменения в ветке `main` не затрагивают уже установленную версию. Чтобы перейти на новую версию, замените `v1.2.3` в адресе на имя свежего тега из раздела Releases этого репозитория и сохраните настройки. Если оформление осталось прежним, обновите страницу с очисткой кэша: `Ctrl+Shift+R` (Windows/Linux) или `Cmd+Shift+R` (macOS).

## Важные замечания

- Тема подключается только через `@import`; копировать её содержимое в поле настроек вручную не нужно.
- В теме остаются внешние ссылки на шрифты и декоративные изображения. Эти ресурсы не хранятся в репозитории и загружаются с внешних адресов.
- Лицензия намеренно не выбрана: перед распространением или изменением темы учитывайте права на сторонние фрагменты и внешние ресурсы.
- После установки отдельно проверьте расположение блока переключателей списков (`.b-list_switchers`) — на некоторых разрешениях он может требовать подстройки.
