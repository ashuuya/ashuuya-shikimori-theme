# Ashuuya — Citrus-based Shikimori theme

**Полное название:** *Ashuuya — Citrus-based Shikimori theme (Monocolor lists + Cosmo sliders).* «Ashuuya» — имя темы; Citrus, Monocolor и Cosmo обозначают её исходные компоненты, а не три альтернативных названия.

## Что означают компоненты

- **Citrus** — базовый дизайн профиля и боковых списков (`prof_form_citrus`).
- **Monocolor** — оформление списков и связанные монохромные элементы (`q02_monocolor_citrus_list`).
- **Cosmo** — дополнительные компоненты Cosmo, включая панель быстрого доступа и слайдеры профиля.
- **RIP adaptation** — адаптации для Shikimori RIP / Live.

## Установка полной темы через @import

1. Создайте **публичный** GitHub-репозиторий `ashuuya-shikimori-theme`.
2. Загрузите в корень репозитория этот `README.md` и `ashuuya-shikimori-theme.css`. Файл `ashuuya-rip-adaptation.css` можно загрузить как отдельный модуль для справки; он уже включён в полную тему.
3. Создайте GitHub Release с тегом `v1.0.0`.
4. В поле пользовательского CSS Shikimori вставьте строку ниже, заменив `<OWNER>` на имя владельца репозитория:

```css
@import url("https://raw.githubusercontent.com/<OWNER>/ashuuya-shikimori-theme/v1.0.0/ashuuya-shikimori-theme.css");
```

5. Сохраните настройки. Если изменения не отображаются, сбросьте кэш импорта на <https://shikimori.rip/tests/reset_styles_cache>, указав тот же URL.

Импортируемый CSS загружается Shikimori и встраивается в пользовательский стиль. `@import` сокращает текст в поле настроек, но сам CSS остаётся того же размера и кэшируется сайтом.

## Файлы

- `ashuuya-shikimori-theme.css` — полная тема; содержит актуальные адаптации и модульный патч. Для полной установки подключайте только её.
- `ashuuya-rip-adaptation.css` — модульный патч для дополнения существующего базового дизайна. Не подключайте его одновременно с полной темой.

## Выпуск обновлений

Оставьте опубликованный тег `v1.0.0` неизменным. Для следующего выпуска создайте новый тег, например `v1.0.1`, загрузите обновлённые файлы и замените версию в строке `@import`. Если кэш Shikimori всё ещё показывает старое содержимое, сбросьте его на странице выше.

## Важные замечания

- Загружайте только файлы из этого набора. Не загружайте исходные `uploads/design.css` или `ashuuya_full_design.css`.
- В полной теме остаются внешние ссылки на шрифты и декоративные изображения; эти ресурсы не хранятся в репозитории.
- Сохранена атрибуция исходных авторов. Перед добавлением `LICENSE` проверьте права на сторонние фрагменты и внешние ресурсы; лицензия намеренно не выбрана.
- После импорта проверьте широкие и мобильные экраны. Отдельно проверьте расположение `.b-list_switchers`.
